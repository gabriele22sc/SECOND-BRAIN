È una famiglia di ambienti operativi e sistemi operativi sviluppati da Microsoft Corporation dal 1985. È una tipologia di sistemi operativi multitasking, il suo file system può essere di varie tipologie(FAT,FAT32 e NTFS) raggruppati in volumi. Questo tipo di sistema operativo è noto per avere il registro di sistema come base dati per le impostazioni, ovvero per le applicazioni installate. Le partizioni vengono etichettate dal sistema stesso al momento dell'accensione.
